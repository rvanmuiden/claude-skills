# claude-skills

A collection of Claude Skills. Each folder is one skill with its own `SKILL.md`.

| Skill | Description |
|---|---|
| [`belangrijke-mails/`](belangrijke-mails/) | Lists the important unread Gmail messages of the last 24 hours with a summary and priority, plus IT vacancies rated against your profile. Read-only. |
| [`critical-prompting/`](critical-prompting/) | Critical sparring partner: tests ideas, plans, texts and analyses using 10 Critical Prompting techniques. |
| [`persuasion-audit/`](persuasion-audit/) | Audits a website or app against Cialdini's 7 principles of persuasion and flags dark patterns. |

## Origin

This repository merges two earlier repositories, with their git history preserved:

- [rvanmuiden/critical-prompting](https://github.com/rvanmuiden/critical-prompting)
- [rvanmuiden/persuasion-audit](https://github.com/rvanmuiden/persuasion-audit), a fork of the original by Ron Gilad. That skill is MIT-licensed; see [`persuasion-audit/LICENSE`](persuasion-audit/LICENSE).
